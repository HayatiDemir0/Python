<h1>🎮 HayatiDemir0 - Python Başlangıç Projeleri</h1>

<p>Bu repo, Python öğrenme sürecimde geliştirdiğim <strong>basit oyunlar</strong> ve <strong>mini uygulamalar</strong> içermektedir. Amacım, hem kendi öğrenimimi pekiştirmek hem de Python’a yeni başlayanlara örnek projeler sunmaktır.</p>

<h2>🕹️ Oyunlar</h2>
<ul>
  <li><strong>SayıTahmini.py</strong> – Bilgisayarın tuttuğu sayıyı tahmin etmeye çalıştığınız oyun.</li>
  <li><strong>HazineOyunu.py</strong> – Basit bir metin tabanlı hazine bulma oyunu.</li>
  <li><strong>taşkağıtmakas.py</strong> – Taş-Kağıt-Makas oyunu.</li>
</ul>

<h2>🧰 Mini Uygulamalar</h2>
<ul>
  <li><strong>hesapmakinesi.py</strong> – Temel matematiksel işlemleri yapan basit hesap makinesi.</li>
  <li><strong>şifreoluşturucu.py</strong> – Rastgele güvenli şifreler oluşturan uygulama.</li>
  <li><strong>hastane.py</strong> – Basit bir hastane kayıt sistemi simülasyonu.</li>
  <li><strong>TrafikIşığı.py</strong> – Trafik ışığı simülasyonu.</li>
  <li><strong>ptt.py</strong> – Basit bir posta/ileti simülasyonu.</li>
</ul>

<h2>🚀 Kurulum ve Çalıştırma</h2>
<p>Projeleri çalıştırmak için:</p>

<pre>
# Repo'yu klonlayın
git clone https://github.com/HayatiDemir0/REPO-ADI

# Klasöre girin
cd REPO-ADI

# Örnek olarak bir projeyi çalıştırın
python SayıTahmini.py
</pre>

<p><em>Python 3.x sürümü önerilir.</em></p>
